# 🎬 Rutube Downloader

<img src="assets/main.png" width="800">

Программа для скачивания видео и сериалов с Rutube.

---

## Возможности

* 🎬 Скачивание отдельных видео
* 📺 Поиск и загрузка сериалов
* 🤖 Автоматический выбор режима загрузки (видео/сериал)
* 🔎 Автоматический поиск сезонов и серий
* 🎚 Выбор качества загрузки
* 👾 Выбор нужных серий 
* 📊 Расчёт размера файлов перед загрузкой
* 💾 Проверка свободного места
* ⚡ Отображение скорости и прогресса загрузки
* ⛔ Остановка загрузки
* ✅ Продолжение загрузки с последнего места
* 🗂 Автоматическая сортировка сериалов по сезонам
* 📁 Дополнительная папка для сохранения видео
* ⚙️ Ограничение количества проверяемых сезонов

---

# Установка

## Windows

1. [Скачайте последнюю версию программы из Releases.](https://github.com/Kirliffilan/RutubeDownloader/releases/latest)
2. Распакуйте архив.
3. Запустите:

```bash
RutubeDownloader.exe
```

---

# Использование

1. В настройках выберите:
- Папку загрузки
- Дополнительную папку для видео (необязательно)
- Необходимое качество
- Необходимое количество сезонов и серий

2. Скопируйте ссылку на видео Rutube.
3. Нажмите **Найти**.
4. Выберите серии.
5. Нажмите **Скачать выбранное**.
6. Дождитесь окончания загрузки.

***Дополнительные функции:***
- **Получить информацию** - выводит информацию о полученном видео. Не запускает поиск серий.
- **Выделить всё/Убрать всё** - добавляет/снимает выделение всех серий.
- **⛔ Остановить** - прерывает загрузку видео. Продолжить с того же места можно, нажав кнопку **Скачать выбранное**

# Настройки

## 📁 Папка сохранения

Выбор папки, куда будут сохраняться скачанные файлы.

Пример:

```
D:\Сериалы
```

---

## 📁 Дополнительная папка для видео

Используется для режима обычного видео.

Если поле пустое:

```
D:\Сериалы
└── Видео.mp4
```

Если указана дополнительная папка:

```
D:\Сериалы
└── Видео
    └── Видео.mp4
```

> Дополнительная папка применяется только к обычным видео. Сериалы всегда сохраняют структуру по сезонам.

---

## 📺 Сохранение сериалов

Для сериалов программа автоматически создаёт структуру:

```
D:\Сериалы
└── Название сериала
    └── 1 сезон
        ├── 1_1 Название серии.mp4
        └── 1_2 Название серии.mp4
```

---

## 🎚 Качество

Выбор качества загружаемого видео:

* Максимальное
* 2160p
* 1440p
* 1080p
* 720p
* 480p
* 360p

Чем выше качество, тем больше размер файла.

---

## 🔎 Параметры поиска

Настройки количества проверяемых сезонов и серий.

Например:

```
Сезонов: 2
Серий: 20
```

Программа будет искать только первые 2 доступных сезона сериала.

Чем больше значения, тем дольше выполняется поиск.

# Решение проблем

## Не найдено видео

Проверьте:

- правильность ссылки;
- доступность видео на Rutube.

---

## Не находятся серии

Попробуйте:

- увеличить количество сезонов или серий в настройках;
- проверить название сериала.

---

## Ошибка загрузки

Попробуйте:

- повторить загрузку;
- проверить интернет-соединение.

**Всегда** можно повторить загрузку через некоторое время, видео продолжит загрузку с последнего места.

# 🎬 Rutube Downloader

Программа для удобного скачивания видео и *сериалов* с Rutube.

## 📥 Установка

### Готовая версия

1. Скачайте последнюю версию программы из раздела **Releases**.
2. Распакуйте архив.
3. Запустите файл:

```text
RutubeDownloader.exe
```

---

# 🚀 Как пользоваться

## 1. Вставка ссылки

После запуска программы:

1. Откройте Rutube.
2. Найдите нужное видео или серию.
3. Скопируйте ссылку.

Пример:

```text
https://rutube.ru/video/xxxxxxxx/
```

Вставьте ссылку в поле:

```text
Вставьте ссылку Rutube...
```

Можно нажать кнопку:

```text
📋
```

для вставки ссылки из буфера обмена.

---

# 2. Получение информации

Нажмите:

```text
Получить информацию
```

Программа покажет:

- название;
- автора;
- сериал;
- сезон;
- серию.

---

# 3. Выбор режима загрузки

Перед поиском выберите режим:

## 🎬 Видео

Используется для:
- отдельных серий;
- фильмов;
- трейлеров;
- обычных видео.

Пример:

```text
Ссылка на 4 сезон 1 серию
↓
Скачать именно эту серию
```

Поиск дополнительных серий не выполняется.

---

## 📺 Сериал

Используется для поиска всех серий.

Программа будет искать:

```text
1 сезон 1 серия
1 сезон 2 серия
...
```

Согласно настройкам количества сезонов и серий.

---

# 4. Настройки загрузки

Откройте:

```text
⚙ Настройки
```

Можно изменить:

---

## 📁 Папка сохранения

Выберите место, куда будут сохраняться файлы.

Пример:

```text
D:\Видео
```

---

## 🎞 Качество

Можно ограничить качество загрузки видео:

```text
Максимальное
2160p
1440p
1080p
720p
480p
360p
```


---

## 🔎 Параметры поиска сериала

Настройки:

```text
Максимум сезонов
Максимум серий
```

Например:

```text
Сезонов: 5
Серий: 20
```

Программа проверит существование каждой серии:

```text
1 сезон 1 серия
1 сезон 2 серия
...
5 сезон 20 серия
```

Чем больше значения, тем дольше поиск.

---

# 5. Поиск серий

Если выбран режим:

```text
📺 Сериал
```

нажмите:

```text
🔎 Найти
```

Программа начнёт поиск:

```text
1 сезон
 ├ 1 серия
 ├ 2 серия
 └ 3 серия

2 сезон
 ├ 1 серия
 └ 2 серия
```

Найденные серии появятся в списке.

---

# 6. Выбор видео

Можно выбрать отдельные элементы:

```text
☑ 1 сезон 1 серия
☑ 1 сезон 2 серия
```

Или выбрать всё:

```text
☑ Выделить всё
```

Убрать выбор:

```text
☐ Убрать всё
```

---

# 7. Скачивание

После выбора нажмите:

```text
⬇ Скачать выбранное
```

Во время загрузки отображается:

- процент;
- скорость;
- оставшееся время;
- журнал действий.

Пример:

```text
45.3%   ⚡ 5.20 MB/s   ⏱ 03:12
```

---

# 8. Остановка загрузки

Чтобы остановить процесс:

```text
⛔ Остановить
```

Текущая загрузка будет прекращена.

---

# 📂 Где находятся файлы

## Сериал

Файлы сохраняются:

```text
Папка сохранения
│
└── Название сериала
    │
    └── 1 сезон
        │
        ├── 1 серия.mp4
        ├── 2 серия.mp4
        └── 3 серия.mp4
```

---

## Обычное видео

Сохраняется:

```text
Папка сохранения
│
└── Название видео
    │
    └── видео.mp4
```

# ⚠ Возможные ошибки

## "Не удалось определить ID видео"

Проверьте ссылку.

Поддерживается формат:

```text
https://rutube.ru/video/...
```

---

## Не находятся серии

Попробуйте:

- увеличить количество сезонов;
- увеличить количество серий;
- проверить название сериала;
- убедиться, что выбран режим:

```text
📺 Сериал
```

---

## Скачивается не та серия

Проверьте режим.

Для конкретной серии используйте:

```text
🎬 Видео
```

Для поиска всех серий:

```text
📺 Сериал
```

---

## Медленная загрузка

Скорость зависит от:

- скорости интернета;
- сервера Rutube;
- выбранного качества.

Видео в 4K может загружаться дольше из-за большого размера файла.

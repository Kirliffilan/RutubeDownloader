# 🎬 Rutube Downloader

Программа для удобного скачивания видео и *сериалов** с Rutube.
```
* сериалы в формате: "Название сезон серия" или "Название серия"
```

## Возможности

- 🎬 Скачивание отдельных видео
- 🔎 Автоматический поиск серий
- 🎚 Выбор качества загрузки
- 📊 Расчёт размера видео перед загрузкой
- 💾 Проверка свободного места на диске
- ⚡ Отображение скорости загрузки
- ⏱ Отображение оставшегося времени
- 📈 Отображение прогресса загрузки
- ⛔ Остановка текущей загрузки
- 💾 Продолжение остановленной загрузки
- 🗂 Автоматическая сортировка сериалов по сезонам

---

# Установка

## Windows

1. [Скачайте последнюю версию программы из Releases.](https://github.com/Kirliffilan/RutubeDownloader/releases/latest)
3. Распакуйте архив.
4. Запустите:

```
RutubeDownloader.exe
```

---

# Использование

## Получение информации

1. Скопируйте ссылку на видео Rutube:

```
https://rutube.ru/video/xxxxxxxx/
```

2. Вставьте ссылку в программу.
3. Нажмите:

```
Получить информацию
```

После этого программа покажет:

- название видео;
- автора;
- название сериала;
- сезон;
- серию.

---

# Режимы работы

## 🎬 Видео

Используется для скачивания одного видео.

Пример:

```
Ссылка на серию
↓
Получение информации
↓
Скачать выбранное
```

---

## 📺 Сериал

Используется для поиска всех серий сериала.

Программа проверяет возможные варианты:

```
1 сезон 1 серия
1 сезон 2 серия
1 сезон 3 серия
...
4 сезон 10 серия
```

Количество проверяемых сезонов и серий можно изменить в настройках.

---

# Поиск серий

Для поиска сериала:

1. Выберите режим:

```
📺 Сериал
```

2. Нажмите:

```
🔎 Найти
```

После завершения поиска появится список найденных серий.

Для каждой серии отображается:

- сезон;
- серия;
- примерный размер файла.

Также показывается:

- общий размер выбранных файлов;
- свободное место на диске.

---

# Настройки

## Папка сохранения

Выберите место, куда будут сохраняться файлы.

Пример:

```
D:\Сериалы
```

---

## Качество

Доступен выбор качества видео:

- Максимальное
- 2160p
- 1440p
- 1080p
- 720p
- 480p
- 360p

---

## Параметры поиска

Можно настроить:

- максимальное количество сезонов;
- максимальное количество серий.
  
*Примечание:* Чем больше выбранное количество сезонов и серий, тем дольше будет длиться поиск.

---

# Загрузка

После выбора видео нажмите:

```
⬇ Скачать выбранное
```

Во время загрузки отображается:

- процент выполнения;
- скорость;
- время до завершения;
- размер файла;
- свободное место.

Пример:

```
45.2%   ⚡ 8.50 MB/s   ⏱ 02:15

Размер: 900 MB
Свободно: 120 GB
```

---

# Остановка загрузки

Для остановки используйте кнопку:

```
⛔ Остановить
```

Во время активной загрузки повторный запуск блокируется, чтобы избежать конфликтов файлов.

---

# Структура сохранения

```
Папка сохранения
│
└── Название сериала
    │
    └── 1 сезон
        │
        ├── 1 серия.mp4
```

---

## Видео

```
Папка сохранения
│
└── Название видео
    │
    └── video.mp4
```

---

# Проверка места

Перед загрузкой программа проверяет:

- размер будущего файла;
- свободное место на диске.

Если места недостаточно, загрузка отменяется.

---

# Решение проблем

## Не найдено видео

Проверьте:

- правильность ссылки;
- доступность видео на Rutube.

---

## Не находятся серии

Попробуйте:

- увеличить количество сезонов или серий в настройках;
- проверить название сериала.

---

## Ошибка загрузки

Попробуйте:

- повторить загрузку;
- проверить интернет-соединение.

**Всегда** можно повторить загрузку через некоторое время, видео продолжит загрузку с последнего места.
